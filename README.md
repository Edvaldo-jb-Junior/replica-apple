# 🍎 Apple Website Replica

Uma réplica moderna da página oficial da Apple desenvolvida para praticar técnicas avançadas de Front-End, design responsivo e reprodução fiel de interfaces profissionais.


## 📖 Sobre o Projeto

O **Apple Website Replica** é um projeto desenvolvido com o objetivo de reproduzir a experiência visual e a identidade da página oficial da Apple utilizando tecnologias
web modernas.

Este projeto foi criado para aprimorar habilidades em:

* Estruturação semântica com HTML5
* Estilização avançada com CSS3
* Responsividade para múltiplos dispositivos
* Organização de componentes visuais
* Boas práticas de desenvolvimento Front-End

O foco principal foi recriar uma interface elegante, minimalista e moderna, inspirada no design característico da Apple.
